Rule-Based Python AI ChatBot 🤖
About

A beginner-friendly, rule-based chatbot built with Python that responds to basic user questions using predefined responses. It also provides personalized greetings based on the time of day.

Features
Personalized, time-based greetings
Predefined responses to user questions
Interactive conversation loop
Simple exit functionality
Technologies Used
Python 3
datetime module
How to Run
Clone this repository.
Open the project folder in your terminal.
Run the command:
   python chatbot.py

Learning Outcomes

This project helped me practice Python fundamentals, including functions, dictionaries, loops, conditional statements, and string handling.
